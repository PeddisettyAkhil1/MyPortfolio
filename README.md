# MyPortfolio — Peddisetty Akhil

> **UX Designer & Game Developer Portfolio** built with React, TypeScript, Tailwind CSS, Framer Motion, and Three.js (React Three Fiber). Featuring an interactive 3D studio, playable Unity demo, capability matrix, and dedicated Admin CMS portal.

## 🚀 Key Features

- **Interactive 3D Studio Workspace**: Real-time WebGL 3D scene built with Three.js / React Three Fiber and OrbitControls.
- **Playable 2D Game Demo**: Embedded HTML5 Canvas Block Dash game runner.
- **Dedicated Admin CMS (`/admin`)**: Secure passcode-authenticated portal (`admin123`) for updating projects, capabilities, personal info, and reading inbox messages in real time.
- **Drag & Drop Image Uploader**: Direct drag & drop image file support in the Admin project manager.
- **Vibe Coding Showcase**: Category filter for AI-assisted rapid prototyping and generative code experiments.
- **Dual Email Notification Engine**: In-browser message storage with automated visitor confirmations and owner alert generation.
- **Ultra-Fast 3D Glass Emblem Startup Loader**: Smooth 1.2s entry animation with progress counter.

## 🛠️ Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **3D & Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Notifications**: Sonner

## 💻 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/PeddisettyAkhil1/MyPortfolio.git
cd MyPortfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
